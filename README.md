# Atari - VCS thumbnails

Snaps of Atari VCS (2021 console) store games, named by their folder in the archive.org item `atari-vcs-complete-store-archive-2026`, in the libretro-thumbnails layout (Named_Snaps), for gameflix.

Sources: the first Steam screenshot of the same game, for the classic 2600/7800 releases the snap of the original from libretro-thumbnails, otherwise a frame of a gameplay video on YouTube (its automatic frames, without overlays).
